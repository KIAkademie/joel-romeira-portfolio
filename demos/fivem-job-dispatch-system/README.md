# GTA 5 / FiveM – Dispatch- & Auftrags-System (Lua & SQL)

Ein Leitstellen- und Auftrags-System für FiveM-Server (z. B. für Abschleppdienst, Mechaniker oder Taxi), bestehend aus einem Lua-Server-/Client-Skript, einer SQL-Tabelle für offene Aufträge und einem NUI-Interface.
