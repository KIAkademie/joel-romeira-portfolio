# GTA 5 / FiveM – Lockpick & Timing-Minispiel (NUI + Lua)

Ein spielbares NUI-Minispiel für GTA 5 / FiveM-Server (z. B. zum Öffnen von Fahrzeugen oder Türen), bestehend aus dem Lua-Client-Skript (`client.lua`, `fxmanifest.lua`) und dem HTML5/JS-Interface, das auch direkt im Browser gespielt werden kann.

- **Direkt im Browser spielen:** [https://kiakademie.github.io/fivem-lockpick-minigame/](https://kiakademie.github.io/fivem-lockpick-minigame/)
