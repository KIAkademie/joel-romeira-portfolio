# Minecraft Redstone-Logik-Simulator & Crafting-Rechner

Ein interaktiver 2D-Simulator für Redstone-Schaltungen (Hebel, Redstone-Leitungen, Inverter/Fackeln und Redstone-Lampen) sowie ein Ressourcen-Rechner für größere Crafting-Projekte.

- **Direkt im Browser ausprobieren:** [https://kiakademie.github.io/minecraft-crafting-redstone-sim/](https://kiakademie.github.io/minecraft-crafting-redstone-sim/)
