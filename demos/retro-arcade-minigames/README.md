# Browser-Minispiele: Snake, Brick-Breaker & Reaktionstest

Drei direkt im Browser spielbare Klassiker in reinem JavaScript und HTML5 Canvas – inklusive Highscore-Speicherung über `localStorage`.

- **Direkt spielen:** [https://kiakademie.github.io/retro-arcade-minigames/](https://kiakademie.github.io/retro-arcade-minigames/)
- **Autor:** Joel Neto Romeira

## Enthaltene Minispiele

1. **Snake:** Klassisches Snake-Spiel auf dem HTML5-Canvas (Steuerung per Pfeiltasten, WASD oder Buttons).
2. **Brick-Breaker:** Ball- & Paddle-Spiel zum Abräumen von Blöcken (Steuerung per Maus oder Pfeiltasten).
3. **Reaktionstest:** Misst die Reaktionszeit in Millisekunden (`ms`) beim Farbwechsel.
